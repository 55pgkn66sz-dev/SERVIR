# SERVIR

Widget Grist (fichier unique `index.html`) de suivi de l'emploi, du recrutement, des visites médicales et de l'instruction dans la réserve.

## Utilisation
1. Héberger `index.html` (par exemple avec GitHub Pages) ou le charger comme widget personnalisé Grist.
2. Régler le nom du service, les modèles de courriels, les liens et les tables dans le back office du widget.
3. Sans Grist, le widget s'ouvre en mode démonstration avec des données fictives.

## Contenu
- `index.html` : le widget (version 3.0.0).
- `docs/candidatures-agorh.md` : création de candidatures depuis un PDF Agorh@.
- `CHANGELOG.md` : journal des versions.

## Tests
Ouvrir `index.html#tests` dans un navigateur (hors Grist) lance la suite de tests intégrée.
